💳 Streaming Service Pricing Page

A clean, responsive pricing page built using HTML and CSS, inspired by streaming service plan pages like Netflix. Displays three subscription tiers side by side, with the middle plan highlighted as the most popular choice.

✨ Features

- Three pricing cards: Basic, Standard, and Premium
- Highlighted "Standard" plan with a gold border to draw attention
- Consistent button alignment across all cards, regardless of content length
- Fully responsive — cards sit side by side on wider screens and stack vertically on mobile
- Clean dark-themed card design with soft shadows

🛠️ Technologies Used

- HTML5
- CSS3

📁 Project Structure

streaming-pricing-page/
|── index.html
|── style.css
🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

📸 Preview

A pricing page featuring three subscription plans — Basic, Standard, and Premium — each listing its price and included features, with a "Choose Plan" button aligned consistently across all cards.
